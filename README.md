# 台球研习室 / Billiards Lab

可操作的浏览器 3D 台球训练原型。TypeScript / Three.js / Vite；客户端计算，无击球服务器。

## 启动

```sh
cd /workspace/billiards
npm install
npm run dev
```

打开 http://localhost:5173 。在自己的电脑上运行项目时，iPad 与电脑连接同一 Wi-Fi，访问 `http://电脑的局域网IP:5173`，允许系统防火墙的 5173 端口。云工作区 IP 不等于用户家庭局域网 IP，需先下载项目到局域网电脑运行，或使用工作区提供的端口转发。

```sh
npm run build
npm test
node tests/browser.mjs
```

构建产物在 dist。浏览器检查脚本默认使用 `/usr/bin/chromium`，可按本机路径修改。

## 操作演示（可复现）

1. 默认白球位于 (0, 0.98)，粉球 (0.035, 0.27)，单位米。第一人称 28%、第三人称 72%，共用同一场景和球局。
2. 选择“摆球”，拖动任意球，轻点选目标；添加和移除按钮可自定义球局。重叠及库外位置不接受。
3. 选择“瞄准”，左右拖动或连续调整角度滑块，微调按钮为 0.1°。取消目标后仍可出杆。
4. 选择袋口，观察几何数据和局部视图。移动击球圆盘，调至低杆或左右塞，设置力度后出杆。
5. 所有球由物理核心继续计算；选择 0.25× 或暂停观察。
6. 运动结束后点击“回放”，拖动时间轴；“撤销”回到出杆前，“相同参数重打”复现。
7. “观察”拖动绕球桌、滚轮/双指缩放；回到瞄准视角重置相机。保存/加载存在本浏览器。

## 模块

- config.ts：SI 配置、袋口、共享直库/袋角线段。
- state.ts：完整球状态（位置、线速度、三维角速度、姿态、半径、质量、惯量、运动状态）。
- physics.ts：台呢、冲量、碰撞、下落和步进；不依赖 Three.js。
- aim.ts：实际射线几何、理想虚拟球、同核心预测。
- prediction.worker.ts：预测线程，独立状态副本，最长 6 秒。
- scene.ts：场景、摄像机、共享几何与渲染。
- main.ts：鼠标/触控与状态机、控制面板。
- history.ts：版本化本地存档；回放记录完整状态。
- tests/：解析、确定性与浏览器验证。
